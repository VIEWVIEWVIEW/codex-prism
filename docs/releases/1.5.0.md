# codex-prism 1.5.0

Desktop builds for **Ubuntu 26.04 LTS (x86_64)** and **macOS (Apple Silicon)**, built from the same v1.5.0 source tag.

## Changes

- Add private local templates, with previews and project creation from full template documents and their assets.
- Add optional visual change reports for agent edits: PDF highlights, numbered cards, rendered before/after excerpts and crops, navigation, and file-level Keep/Undo. Reports are off by default; enable **Changes** beside **Auto** in the PDF toolbar before an agent turn.
- Keep unsupported changes explicitly unplaced and show compilation failures instead of misleading highlights. PDF binary changes are excluded from report cards.
- Recompile after accepting changes, including when Auto is off. Auto now recompiles after agent edits without waiting for pending review decisions.
- Make the chat input vertically resizable and add a persistent editor font-size selector (10–32 px).
- Copy uploaded images into an existing project image folder or create `prism-uploads`; instruct the agent to copy external figures into the project and use relative paths.
- Improve PDF responsiveness, give PDF exports project-and-timestamp filenames, and simplify the PDF toolbar.
- Update the scientific writing guidance supplied to the agent.

## Ubuntu installation

Install `codex-prism-1.5.0-linux-x86_64.deb` with `sudo apt install ./codex-prism-1.5.0-linux-x86_64.deb`, or make the AppImage executable and run it. These packages target Ubuntu 26.04; older distributions are not guaranteed to work.

Install system TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.5.0-macos-arm64.dmg` and copy codex-prism into Applications. Install the LaTeX compiler using Homebrew:

```sh
brew install --cask mactex-no-gui
```

The app detects the CLI bundled at `/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex`, or uses your configured Codex executable.

The macOS app is ad-hoc signed, **not Apple-notarized**. After the initial blocked launch, use System Settings → Privacy & Security → Open Anyway to approve it.

## Requirements and verification

Connect your Codex account through the application or an installed Codex CLI. TeX Live/MacTeX is required to compile LaTeX; existing PDFs can be viewed without it. Python and scientific skills are optional. Node.js and Rust are not needed to run the packaged application.

Verify downloads against `SHA256SUMS`. Automatic updates are not enabled.
