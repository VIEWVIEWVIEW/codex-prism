# codex-prism 1.6.0

Desktop builds for **Ubuntu 26.04 LTS (x86_64)** and **macOS (Apple Silicon)**, built from the same v1.6.0 source tag.

## Changes

- Run multiple agent chats concurrently in isolated project copies. Review each chat's changes and use **Keep** to merge them into the main document, or discard them independently.
- Merge non-overlapping edits while preserving previously accepted work. Conflicts leave the main document unchanged and can be resolved with **Fix with agent** before reviewing again.
- Keep the normal document editor and PDF controls in place. Switching chats selects that chat's PDF; the last successful PDF remains visible during follow-up and repair turns.
- Restore the familiar green **Keep** button and improve temporary-directory access and command-approval handling for isolated agents.
- Use the first request for each accepted set of changes as a shortened Git commit subject, with change details in the body. Full prompts remain optional; follow-ups preserve the original subject until Keep or discard.
- Organize projects into virtual folders without a recent-project retention limit.
- Show existing PDF thumbnails in All Projects and virtual folders, including custom filenames and compiler build outputs, without compiling projects just to preview them.
- Continue Markdown lists with Shift+Enter in chat.
- Resize template previews correctly after dialog layout changes.

## Existing projects

Pending legacy project reviews must be resolved before starting concurrent proposals. Manual source editing remains locked while agents are running or changes await review. Closing a chat does not discard its unresolved work.

## Ubuntu installation

Install `codex-prism-1.6.0-linux-x86_64.deb` with `sudo apt install ./codex-prism-1.6.0-linux-x86_64.deb`, or make the AppImage executable and run it. These packages target Ubuntu 26.04; older distributions are not guaranteed to work.

Install system TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.6.0-macos-arm64.dmg` and copy codex-prism into Applications. Install the LaTeX compiler using Homebrew:

```sh
brew install --cask mactex-no-gui
```

The app detects the CLI bundled at `/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex`, or uses your configured Codex executable.

The macOS app is ad-hoc signed, **not Apple-notarized**. After the initial blocked launch, use System Settings → Privacy & Security → Open Anyway to approve it.

## Requirements and verification

Connect your Codex account through the application or an installed Codex CLI. TeX Live/MacTeX is required to compile LaTeX; existing PDFs can be viewed without it. Python and scientific skills are optional. Node.js and Rust are not needed to run the packaged application.

Optimized ebook export additionally requires Ghostscript (`sudo apt install ghostscript` on Ubuntu or `brew install ghostscript` on macOS). Images may lose detail; the working PDF remains unchanged.

Verify downloads against `SHA256SUMS`. Automatic updates are not enabled.
