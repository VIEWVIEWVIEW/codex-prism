# codex-prism 1.4.2

Desktop builds for **Ubuntu 26.04 LTS (x86_64)** and **macOS (Apple Silicon)**, built from the same v1.4.2 source tag.

## Changes

- Reduce review processing overhead by loading review file contents on demand and moving large diff calculations into a background worker.
- Avoid unnecessary LaTeX recompilations when an open document's contents have not changed.
- Refresh project files incrementally and coalesce file-change notifications to reduce repeated reads and refreshes.
- Batch streamed chat updates, memoize messages, and defer rendering older chat history to keep long conversations responsive.
- Fix project history initialization when an existing legacy history repository is empty.

## Ubuntu installation

Install `codex-prism-1.4.2-linux-x86_64.deb` with `sudo apt install ./codex-prism-1.4.2-linux-x86_64.deb`, or make the AppImage executable and run it. These packages target Ubuntu 26.04; older distributions are not guaranteed to work.

Install system TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.4.2-macos-arm64.dmg` and copy codex-prism into Applications. Install the LaTeX compiler using Homebrew:

```sh
brew install --cask mactex-no-gui
```

The app detects the CLI bundled at `/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex`, or uses your configured Codex executable.

The macOS app is ad-hoc signed, **not Apple-notarized**. After the initial blocked launch, use System Settings → Privacy & Security → Open Anyway to approve it.

## Requirements and verification

Connect your Codex account through the application or an installed Codex CLI. TeX Live/MacTeX is required to compile LaTeX; existing PDFs can be viewed without it. Python and scientific skills are optional. Node.js and Rust are not needed to run the packaged application.

Verify downloads against `SHA256SUMS`. Automatic updates are not enabled.
