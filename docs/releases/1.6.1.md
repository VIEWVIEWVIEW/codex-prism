# codex-prism 1.6.1

Desktop builds for **Ubuntu 26.04 LTS (x86_64)** and **macOS (Apple Silicon)**, built from the same v1.6.1 source tag.

## Changes

- Restore each project's open chat tabs, active conversation, message history, and unsent drafts after restarting. Projects without saved tab state reopen their latest conversation; agents are not automatically restarted.
- Refresh visible PDF pages when display pixel density changes or the app returns to the foreground, addressing stale or blurry rendering after window restoration.
- Add **Copy link address** to the right-click menu for links in chat activity, commentary, and final answers.
- Hide **Keep** when a proposal has no changed files.
- Clarify that scientific skills are optional and available under **Settings → Environment → Scientific Skills**, with regression coverage ensuring setup never opens automatically.

## Ubuntu installation

Install `codex-prism-1.6.1-linux-x86_64.deb` with `sudo apt install ./codex-prism-1.6.1-linux-x86_64.deb`, or make the AppImage executable and run it. These packages target Ubuntu 26.04; older distributions are not guaranteed to work.

Install system TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.6.1-macos-arm64.dmg` and copy codex-prism into Applications. Install the LaTeX compiler using Homebrew:

```sh
brew install --cask mactex-no-gui
```

The app detects the CLI bundled at `/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex`, or uses your configured Codex executable.

The macOS app is ad-hoc signed, **not Apple-notarized**. After the initial blocked launch, use System Settings → Privacy & Security → Open Anyway to approve it.

## Requirements and verification

Connect your Codex account through the application or an installed Codex CLI. TeX Live/MacTeX is required to compile LaTeX; existing PDFs can be viewed without it. Python and scientific skills are optional. Node.js and Rust are not needed to run the packaged application.

Optimized ebook export additionally requires Ghostscript (`sudo apt install ghostscript` on Ubuntu or `brew install ghostscript` on macOS). Images may lose detail; the working PDF remains unchanged.

Verify downloads against `SHA256SUMS`. Automatic updates are not enabled.
