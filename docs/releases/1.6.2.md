# codex-prism 1.6.2

Desktop packages for **Ubuntu 26.04 LTS x86_64**, **Windows 10/11 x64**, and **macOS Apple Silicon**, built from the same v1.6.2 source tag.

## Changes

- Add a Windows GUI installer with per-user installation, Start menu and uninstall entries, and setup for missing Codex, MiKTeX and WebView2 prerequisites. Existing usable TeX installations are preserved. Ghostscript setup is optional; original PDF export remains available without it.
- Improve Windows tool discovery, including stale PATH environments, npm-installed Codex, and 32-bit/64-bit installation locations. Keep TeX compiler and bibliography tools within one distribution, and configure newly installed MiKTeX through its explicit per-user path.
- Fix outline navigation to the displayed PDF when source lines move, another PDF exists on disk, or compilation is running or has failed. Normalize Windows project paths so navigation uses the compiled source snapshot. Improve SyncTeX lookup coverage and performance.
- Include images referenced by literal LaTeX paths in document-history commits, including PDF figures and existing untracked figures referenced by accepted agent changes. Support graphics search paths and omitted image extensions while excluding compiled document output. Missing or external assets produce a history error; macro-generated filenames are not resolved automatically.
- Fix AppImage packaging with a portable `.DirIcon`, validate the extracted package, and remove `linux` from AppImage filenames to follow catalog conventions.
- Build all platforms through GitHub Actions and collect packages, checksums and source provenance into one release.

## Windows installation

Run `codex-prism-1.6.2-windows-x86_64-setup.exe`, then open the app and use **Connection → Sign in**.

Setup reuses existing tools and installs missing Codex and MiKTeX through WinGet, plus WebView2 when needed. Internet access and Windows App Installer (WinGet) are required for those downloads. A newly installed MiKTeX is configured to download missing packages; existing distribution settings are preserved. Ghostscript's optional setup wizard enables optimized PDF export and may request administrator approval. Silent setup skips this optional wizard.

The Windows installer is unsigned. Prerequisites are separate installations and remain installed when codex-prism is removed.

## Ubuntu installation

Install `codex-prism-1.6.2-linux-x86_64.deb`:

```sh
sudo apt install ./codex-prism-1.6.2-linux-x86_64.deb
```

Or make the AppImage executable and run it:

```sh
chmod +x codex-prism-1.6.2-x86_64.AppImage
./codex-prism-1.6.2-x86_64.AppImage
```

These packages target Ubuntu 26.04; older distributions are not guaranteed to work. Install/authenticate Codex separately, and install TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.6.2-macos-arm64.dmg` and copy codex-prism into Applications. Install/authenticate Codex separately and install MacTeX, for example:

```sh
brew install --cask mactex-no-gui
```

The app detects Codex bundled with ChatGPT or uses your configured executable. The macOS app is ad-hoc signed, **not Apple-notarized**. After a blocked initial launch, use **System Settings → Privacy & Security → Open Anyway** to approve it.

## Requirements and verification

Existing PDFs can be viewed without a LaTeX compiler. Python environments and scientific skills are optional. Node.js and Rust are not required to run the packaged application.

Optimized PDF export additionally requires Ghostscript (`sudo apt install ghostscript` on Ubuntu or `brew install ghostscript` on macOS). Verify downloads against `SHA256SUMS`; `release.json` records the source commit and package hashes. Automatic application updates are not enabled.
