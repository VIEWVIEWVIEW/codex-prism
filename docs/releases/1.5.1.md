# codex-prism 1.5.1

Desktop builds for **Ubuntu 26.04 LTS (x86_64)** and **macOS (Apple Silicon)**, built from the same v1.5.1 source tag.

## Changes

- Track document history in ordinary Git repositories, with history accessible in the app and descriptive summaries for accepted agent changes.
- Accept all pending changes at once with Keep all.
- Show section and subsection numbering in the outline, and navigate to the corresponding PDF location when available.
- Improve LaTeX typing responsiveness and delay automatic compilation until 15 seconds after edits.
- Reduce PDF rendering memory use and coalesce zoom updates to prevent freezes while scrolling and zooming.
- Offer optimized ebook PDF export using Ghostscript, alongside original-quality export. Show size savings and retain the original if compression does not make it smaller.
- Point the GitHub icon to the GitHub repository.

## Ubuntu installation

Install `codex-prism-1.5.1-linux-x86_64.deb` with `sudo apt install ./codex-prism-1.5.1-linux-x86_64.deb`, or make the AppImage executable and run it. These packages target Ubuntu 26.04; older distributions are not guaranteed to work.

Install system TeX Live for compilation:

```sh
sudo apt install texlive-latex-extra texlive-publishers texlive-fonts-recommended texlive-xetex texlive-luatex texlive-bibtex-extra biber
```

## macOS installation

Open `codex-prism-1.5.1-macos-arm64.dmg` and copy codex-prism into Applications. Install the LaTeX compiler using Homebrew:

```sh
brew install --cask mactex-no-gui
```

The app detects the CLI bundled at `/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex`, or uses your configured Codex executable.

The macOS app is ad-hoc signed, **not Apple-notarized**. After the initial blocked launch, use System Settings → Privacy & Security → Open Anyway to approve it.

## Requirements and verification

Connect your Codex account through the application or an installed Codex CLI. TeX Live/MacTeX is required to compile LaTeX; existing PDFs can be viewed without it. Python and scientific skills are optional. Node.js and Rust are not needed to run the packaged application.

Optimized ebook export additionally requires Ghostscript (`sudo apt install ghostscript` on Ubuntu or `brew install ghostscript` on macOS). Images may lose detail; the working PDF remains unchanged.

Verify downloads against `SHA256SUMS`. Automatic updates are not enabled.
